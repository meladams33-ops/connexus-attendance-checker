Connexus Attendance Checker

Creates a grades 3–8 only report and highlights the entire student row when the attendance pattern needs review.

Flags a row when:
1) The first recorded attendance mark is A instead of P.
2) There is a blank between recorded P/A marks on an active attendance date.

Leading/trailing blanks and schoolwide blank dates (holidays/non-attendance days) are ignored.

Choose the “All Attendance Records” Excel file downloaded from Connexus.

The original file is not changed. This tool creates a new copy ending in _CHECKED.xlsx.
